## Runtime workload

The saved v3.0-A diagnostics measure decoded source seconds, not per-stage wall
time. Coarse analysis covered 2,046.165 source seconds. Rescue decoded 29.000
seconds across 9 windows; end refinement decoded 62.250 seconds across 15
windows. The full fresh run took 590.16 seconds. This shows that coarse video
and audio decoding remain the dominant workload, but the 0.32x gate leaves
only about 64.3 seconds of aggregate wall-time headroom. A2 must keep alternate
proposal windows rare and local.

## A2 decision

1. Add an alternate two-hit audio-pair trigger only when coarse motion is
   clearly bilateral, then require the existing dense visual gate.
2. Permit a strong compact audio cluster with slightly one-sided coarse motion
   to reach dense validation; do not relax the dense side-balance requirement.
3. Keep dense bursts separated at real valleys and never union them into an
   adjacent coarse candidate without continuity evidence.
4. Add one conservative long-candidate anti-merge exception for a sustained
   no-audio valley plus an unusually strong visual restart.
5. Preserve end refinement and the start-boundary path unchanged.
