# v3.0-B results

v3.0-B adds a persistent `idle -> active -> ending -> idle` state trace to the
existing 2 fps coarse timeline, plus conservative 8 fps validation of selected
structural split boundaries. The A2 rescue and end-refinement paths remain in
place. This note contains no source paths or player names.

All numbers below come from fresh decoding of the three raw benchmark videos
with the same committed 142-rally manifest, ROIs, and source settings used for
A2. “Frozen” is the original committed baseline; A2 is the fresh pre-change
rerun; B is the final implementation.
